# GUI

## 启动

需要 Bun >= 1.4.0。首次安装会下载 Electron。

```sh
bun install --no-save

# 独立 Web 可执行文件
bun run build:web
./dist/web/opi-web --cwd /path/to/project

# 只构建桌面应用目录，直接预览
bun run build:desktop --dir
bun run desktop

# 当前系统的桌面分发包
bun run build:desktop
```

Windows 的 Web 产物为 `dist/web/opi-web.exe`。Desktop 应用名和可执行文件名为 `opi-desktop`。分发文件位于 `dist/desktop/release/`，Linux 为 `opi-desktop.AppImage`，macOS 为 `opi-desktop.dmg`，Windows 为 NSIS 安装程序 `opi-desktop.exe`。MVP 未配置签名、macOS 公证或自动更新。三平台分别构建，不把 Linux 构建成功视为其他平台已经验证。

`bun run dev:web` 构建前端后从源码启动 Web 服务，不提供热更新。

`opi-web -h` 或 `--help` 查看参数及默认值。`-p` 是 `--port` 的简写，端口须为 0–65535 的十进制整数，`0` 表示自动分配。`--cert` 和 `--key` 必须同时指定。参数错误输出到 stderr，并以状态码 1 退出。

本仓库不提供预构建文件。两个本地构建产物都包含 SDK 和所需运行资源，不要求用户安装 Bun、Node.js 或仓库依赖。Bash、Git、语言服务器等外部工具仍按使用场景由用户安装。Desktop 不需要另外安装 `opi-web` 或 `opi`。

沿用 `~/.pi/agent` 的配置、认证和会话，支持用 `PI_CODING_AGENT_DIR` 覆盖该目录。GUI 直接读取共享 `sessions/` 下各工作区的历史，无需导入或迁移。Web 读取的是后端电脑上的数据，不是访问网页的手机或电脑的本地目录。

Web 内嵌资源使用与 CLI 相同的内容寻址缓存。输入历史与 TUI 共用 `~/.pi/cache/user-history/history.jsonl`，按工作目录隔离。

## Desktop 卡顿诊断

桌面应用自动将发送、新建、切换和列表刷新的时间线写入 Electron 日志目录中的 `gui-timing.jsonl`。macOS 默认为 `~/Library/Logs/opi-desktop/`，其他平台为应用用户数据目录下的 `logs/`。日志异步写入，单文件达到 2 MiB 后轮转为 `gui-timing.jsonl.1`，只保留这两份。正常退出会等待日志写完，写入失败不会阻止聊天。

日志只包含操作名、会话和请求标识、推送批次、时间与成功/失败状态，不记录消息正文、附件、工作区路径或认证内容。时间字段为 Unix 毫秒。

- `main_received`：主进程收到操作。`submittedAt` 是渲染进程调用发送桥接的时间，`requestId` 关联后续请求记录。
- `backend_received`：SDK 后端收到请求。
- `user_available`：后端首次观察到当前会话状态中的新用户消息，尚未经过推送队列。`userTimestamp` 是消息时间，`sessionId` 关联发送请求。这证明消息已进入会话状态，不代表文件已经落盘。
- `user_snapshot`：主进程收到包含用户消息的会话状态。`backendSentAt` 是后端发出时间，`userTimestamp` 是其中最新用户消息的时间。`full: true` 也可能是打开旧会话时重放历史。
- `renderer_received`：渲染进程收到推送。
- `renderer_applied`：前端解码并通知状态订阅者后发出确认。`appliedAt` 是确认发出时间，不代表屏幕绘制完成。使用同一 `run`、`generation`、`deliveryId` 关联推送记录。
- `request_settled`：操作完成或失败。对于聊天请求，此阶段通常在整轮回答结束后出现，不是首条用户消息出现的时间。

发生延迟后保留这两份日志及大致发生时间，可区分桥接、后端准备、推送接收和前端处理阶段。排查首次发送时，应排除 `userTimestamp` 早于本次 `submittedAt` 的历史重放。时钟调整会影响跨进程时间差，日志不单独证明某段代码是根因。

## GUI 设置

左栏“设置”按外观、交互、会话行为、自动标题、终端工具、文件工具、默认工具、网络与网页、权限与安全、子代理、代码智能、集成、终端界面分类。宽屏使用左侧纵向分类，窄屏使用顶部分类选择器。浮窗通过 Grid/Flex 和视口相对尺寸布局，切换分类时尺寸不变，长内容在右侧独立滚动。选择器复用 shadcn/ui Select，支持键盘导航。

外观和交互设置不依赖活动会话，保存后直接应用，不重载 Agent，也不打断任务。会话行为页保留自动压缩、重试、图片处理、消息队列和完整 `settings.json` 编辑入口。外观和交互在打开设置或窗口返回前台时重新读取外部修改。

默认配置为安装目录的 `agent/defaults/gui.jsonc`，用户覆盖为 `~/.pi/agent/configs/gui.jsonc`。支持 `PI_CODING_AGENT_DIR` 改变用户目录，以及 `PI_GUI_CONFIG` 单独指定文件路径。不读取项目层。Web 编辑的是后端电脑上的配置，连接同一宿主的页面会收到保存后的设置。

| 字段 | 默认值 | 用途 |
| --- | --- | --- |
| `theme` | `"system"` | 跟随系统，也可选择 `"light"` 或 `"dark"` |
| `themeColor` | `"#007AFF"` | `#RRGGBB` 主题色，由调色板生成组件颜色 |
| `fonts.ui` | `[]` | 界面与对话字体链，按优先顺序排列 |
| `fonts.code` | `[]` | 代码、路径与日志字体链，按优先顺序排列 |
| `fontSizes.ui` | `14` | 界面基准字号 |
| `fontSizes.chat` | `16` | 对话基准字号 |
| `fontSizes.code` | `14` | 代码基准字号 |
| `sendShortcut` | `"mod-enter"` | Ctrl/⌘+Enter 发送，也可选择 `"enter"` |
| `sessionCache.idleLimit` | `3` | 已超时且可安全释放的实例最多保留数，非负整数，`0` 表示不保留此类实例 |
| `sessionCache.idleMs` | `60000` | 进入淘汰候选的空闲时长和回收扫描间隔，单位毫秒，整数范围 1–2147483647 |

主题色选择器提供预设色、色相/饱和度/明度滑块及 HEX 输入。调整时实时预览，释放滑块、键盘调整结束或 HEX 输入确认后保存。输入失焦也会保存合法值，非法输入不写入配置。保存冲突时撤销预览并显示错误。可单独重置主题色，恢复全部默认设置也会清除主题色覆盖。

配色沿用 OneChat 的 OKLab 混色与对比度校正机制。深浅模式使用同一主题色，按钮、链接、焦点、文本选择和用户消息气泡自动适配，大面积表面只轻微染色。实际强调色可能因可读性调整而不同于输入色。成功、警告、错误和代码高亮保留各自语义颜色。

字号以 px 输入，范围为 8–48，允许小数。辅助信息和标题按固定比例派生，内部相对单位继续响应浏览器缩放。界面字号不改变对话正文和代码字号。选择 Enter 发送时，Shift+Enter 换行，Ctrl/⌘+Enter 仍可发送。输入法组字和补全菜单优先处理键盘事件。

字体设置使用有序字体链。点击字体设置可添加、修改、上移、下移或删除字体，第一项优先。输入框同时支持手写名称和本机字体补全，选择候选、按 Enter 或点击添加 / 保存后写入配置，不逐键保存。方向键选择候选，Escape 先关闭补全，再撤销输入草稿。已添加的字体不能重复添加，代码字体不限制为等宽字体。保存失败时保留草稿，字体链不变。

点击“读取本机字体”后才请求访问权限，界面与代码字体共享本次设置中读取的列表，可手动刷新。Desktop 使用本机字体。Web 使用访问网页的设备字体，需要浏览器支持本地字体访问、安全上下文和用户授权。HTTPS、localhost 和 127.0.0.1 可提供安全上下文，普通局域网 HTTP 地址不能使用此 API。不支持或未授权时仍可手写字体，不使用后端字体列表代替。读取到非空列表后，未列出的已选字体显示“本机列表未找到”，但不阻止保存或改写配置。

配置中的每项是一个字体族名称，不是逗号分隔的 CSS 字体串。例如：

```json
{
  "fonts": {
    "ui": ["Inter", "Noto Sans SC", "Apple Color Emoji"],
    "code": ["JetBrains Mono", "Noto Sans Mono CJK SC"]
  }
}
```

浏览器按顺序为字符选择字体。界面字体链末尾固定追加 `system-ui, sans-serif`，代码字体链末尾固定追加 `ui-monospace, monospace`，无需写入配置。空数组或删除对应覆盖项表示系统默认。预览展示整条字体链的中英文、数字、符号、表情和代码效果。

字体字段已改为数组，不再接受旧的单字体字符串。旧配置如 `"ui": "Inter"` 需改为 `"ui": ["Inter"]`。旧默认值 `"system-ui"` 和 `"monospace"` 可改为 `[]`，也可直接删除对应覆盖项。

表单只写覆盖项，保留 JSONC 注释，也可直接编辑完整文件。回转箭头图标重置对应设置，底部图标恢复全部 GUI 默认设置。配置校验失败时显示错误，并允许通过编辑器修复。保存使用原文校验和原子替换，拒绝覆盖编辑期间的外部修改。

### 模块全局配置

设置页提供十份 `agent/defaults/` 配置的用户层编辑入口，另提供 `tools.jsonc` 编辑入口。除已有的会话行为页外，模块配置不需要活动会话。路径沿用各模块的配置加载器，包括模块专属环境变量重定向，界面显示后端实际路径。

常用开关、数字、枚举和列表使用 shadcn/ui 表单。审批规则、LSP 服务器定义、子代理覆盖、提示词、模板和其他参数在同页切换到 JSONC 编辑。默认工具的 `defaults` 和模型匹配 `rules` 当前通过 JSONC 编辑。默认配置可展开只读查看。

表单区分“继承默认”和“全局覆盖”。重置删除覆盖字段，不写入当前默认值。显式设置为默认值仍保留覆盖。列表每行一项，整体替换默认列表。禁止访问路径列表尤其需要保留仍要保护的条目。

模块配置采用显式保存，保留 JSONC 注释。切换分类保留草稿，关闭设置时确认是否放弃修改。保存前校验 JSONC 和模块 schema，使用原文版本检查及原子替换，拒绝覆盖外部修改。发生冲突后可先复制草稿，再放弃修改并重新读取。

保存仅写全局文件，不重载或中断当前任务。模块下次读取配置时应用修改，已加载的组件需要在任务结束后重载或重启。支持项目层的模块会显示项目配置候选路径，此页不计算项目最终生效值。Cookie、权限审批和 Discord 详细档案旁提供安全或隐私提示。搜索 API 密钥建议使用环境变量引用，JSONC 编辑器不会遮蔽文件中的明文值。

## 消息发送模式

输入框中工具按钮旁的图标与文字按钮可点击切换 Steering（引导）和 Follow-up（跟进），默认 Steering。选择仅在当前界面临时生效，不写入全局配置，刷新或重启后恢复默认。窄屏只显示图标。

任务运行中，Steering 在下一次可介入时引导任务，Follow-up 等当前任务结束后处理。切换不改变已排队消息。运行中有输入时，发送按钮显示对应模式图标，无输入时显示停止图标。空闲时显示向上箭头，正常发起对话。

## 可拖拽布局

宽屏下拖动左右分隔线调整侧栏宽度。消息正文两侧的感应区可连续调整正文与输入器宽度，边缘高光只在鼠标靠近时显示，并跟随鼠标纵向位置。左栏会话与文件区之间的横向分隔线调整文件浏览区域的高度。

所有拖拽边框均支持双击恢复该项默认值，不重置其他尺寸。键盘方向键微调，Home 或 Enter 恢复默认，Esc 取消当前拖动。默认左栏宽度为 20%，右栏为聊天工作区的 34%，对话最大宽度为 100ch，左栏会话区域占可分配高度的 55%。实际尺寸受窗口空间和最小可操作尺寸约束。

尺寸保存为客户端本地布局状态，不进入 `gui.jsonc`。只有完成拖动或重置时保存，窗口变小和切换手机布局不会覆盖记住的宽屏尺寸。Desktop 与各浏览器分别保存，窄屏继续使用抽屉、上下分屏和会话/文件切换。

## Web 访问与手机

参数及默认值见 `opi-web --help`，访问地址以启动输出为准，无需登录或访问密钥。监听 `0.0.0.0` 时，本机访问需将输出地址中的主机替换为 `127.0.0.1`，其他设备访问需替换为电脑的局域网 IP，保留协议和端口，并确保防火墙允许该端口。仅本机使用时可指定 `--host 127.0.0.1`。

所有能连接该端口的设备都能控制后端电脑上的文件和进程。仅用于可信局域网，请勿暴露到公网。同源校验不代替身份认证。

浏览器刷新、断网或手机锁屏不结束后台任务。重连后读取 SDK 当前状态和尚未处理的审批，不自动重发操作。

TLS 可选：

```sh
./dist/web/opi-web --cwd /path/to/project --host 0.0.0.0 \
  --cert /path/to/cert.pem --key /path/to/key.pem
```

使用 TLS 时，通过 HTTPS 访问，端口以启动输出为准。证书需要被设备信任，并匹配访问地址中的 IP 或域名。当前没有可信反向代理配置，不接受代理转发的协议头。

宿主支持单用户、多会话并行。各页面独立选择会话，同一会话在宿主内只使用一个运行实例。切换、刷新和断线不停止后台任务，审批响应只消费一次。操作携带提交时的目标会话，停止当前会话不会取消其他会话。此功能不提供多用户权限隔离。

实例按需加载，无人查看的空闲实例按最近使用顺序和空闲时长回收。执行、排队、等待交互和后台命名期间保活。回收不删除会话，重新打开会恢复历史和本次宿主运行期间的会话授权，项目的“仅本次信任”也在当前宿主内复用。关闭宿主会取消任务并等待必要写入，不支持进程崩溃后自动续跑。

回收策略通过设置页的“编辑 gui.jsonc”配置，不提供单独表单：

```jsonc
{
  "sessionCache": {
    "idleLimit": 3,
    "idleMs": 60000
  }
}
```

未超时的实例全部保留，不占用 `idleLimit` 额度。每次扫描只将已超时且可安全释放的实例纳入淘汰候选，按 `lastUsed` 保留最近使用的 `idleLimit` 个，其余释放。候选数量未超过额度时，即使持续闲置也会保留。运行中、排队和等待交互等实例仍受原有保护，不进入候选池。

`idleMs` 同时控制超时判断和扫描间隔，超时只是进入候选池的门槛，不代表到时必然释放。`idleLimit: 0` 也必须先超时，再在扫描时释放。总实例数可以超过 `idleLimit`：不可回收的实例、未超时的实例，以及额度内保留的超时实例都会驻留。

Web 和 Desktop 均在宿主启动时读取策略。在 GUI 保存后立即更新策略，已有回收计时器按新间隔重新计时，不重载或中断会话。直接修改文件需要重启宿主，或在 GUI 中重新保存。启动时配置无效则使用默认策略，仍可进入设置修复。

逻辑会话 `GuiSession` 长期登记，SDK、执行期任务和载荷由可回收的 `GuiExecution` 持有。回收、删除和退出共用资源收尾，但分别检查准入条件。登记不代表已经加载，未落盘会话也可通过统一打开入口恢复。初始状态重放不建立临时订阅，也不触发额外读取。

导航身份独立于聊天快照。同工作区切换、执行资源加载和重连不会清空文件预览、目录展开或侧栏搜索。全局配置查询不随会话切换重建，文件与 Git 查询属于工作区，不加载 SDK 实例。

页面隐藏后只接收会话概览，返回前台再订阅当前会话详情。草稿、附件、聊天阅读位置和主要展开状态在页面内按会话保存，不依赖运行实例。草稿和附件不保证刷新后保留。多个会话仍可能操作同一项目文件，Git 差异属于工作区，不属于单个会话。

## 界面

界面使用 shadcn/ui 和 Lucide，主布局使用 CSS Grid/Flex。桌面左栏可折叠为图标栏，窄屏左栏使用抽屉，切回桌面宽度时自动关闭。右侧会话信息栏与聊天区分屏，窄屏改为上下排列，各区域独立滚动。分屏和居中悬浮窗使用弹性布局与相对尺寸，不通过绝对定位排列。

配色、磨砂层次、字体与间距、组件状态及响应式布局约束统一记录在 [GUI 设计语言](../DESIGN.md)。

聊天顶栏的“会话操作”菜单提供系统提示词、命令帮助、导入和导出。设置、认证、模型、套餐用量与重载资源按此顺序位于左栏底部。输入框底部的工具按钮显示启用数量，点击打开工具配置。模型、工具、设置、认证、系统提示词和命令帮助均使用悬浮窗。欢迎页的快捷入口只填入草稿，不自动发送。

会话信息栏默认展开，包含会话树、会话统计和遥测。三个页面随会话变更自动更新，流式变更合并读取，不提供手动刷新。顶栏按钮可收起或展开，收起后保留所选标签。切换会话时默认展开，打开悬浮窗不会关闭会话信息栏。

点击会话树的消息正文可定位聊天位置，自动展开所在处理过程。旧分支和已压缩消息在聊天区只读预览，不改变活动分支，点击“返回当前会话”退出预览。树中的切换、总结后切换、创建分支和标签按钮仍执行对应 SDK 操作。

聊天和会话树超过 100 行后只挂载视口附近的行。定位目标、获得焦点的行和文本选区保留挂载，过程与通知的展开状态、已测量行尺寸随会话视图保存。切换回来恢复阅读位置，不重放上一次消息定位。输入草稿不重新渲染未变化的聊天。浏览器原生查找仅覆盖已挂载内容，需要查找完整正文时可导出 HTML。

历史会话和工作区目录在连接时全量发送，后续复用未变化区间，只发送修改记录和顺序变化。重连重新建立全量基线，背压合并以最后实际发送的状态为准。

界面按钮发送类型化的 GUI 操作，后端直接调用 SDK 接口或已注册的处理函数，不模拟斜杠输入，不写入输入历史。手动输入斜杠命令仍走原有流程。

左栏顶部显示工作区选择器，同时决定会话和文件的范围。下方分为会话管理和项目文件两个独立滚动区，分隔线可拖动，也可用方向键调整，比例在当前客户端持久化，双击恢复默认。文件区可收起为底部工具栏上方的一行，不关闭右侧预览。窄屏和可用高度不足时通过“会话 / 文件”切换浏览区域。工作区下拉框支持路径筛选，先列出启动目录，再列出历史中的不同工作区。桌面端“选择目录”打开系统目录选择器，Web 端打开服务端目录浏览弹窗，支持输入路径、返回上级和筛选子目录，不上传浏览器本机目录。

当前工作区的会话条目在运行时显示强调色渐变光带，前端颜色最深，尾部逐渐变淡。光带沿边框周长匀速移动，每圈 6 秒，不表示完成百分比。结束且未读时光带闭合成完整边框，已读后恢复普通样式。等待交互时使用静态边框和审批图标。其他工作区有运行任务、待确认或未读结果时，工作区选择按钮显示静态强调色边框。下拉选项不显示边框动画，在原勾选位置显示状态：待审批为实心小盾，运行中为呼吸圆点，未读为实心圆点。其他工作区有待审批会话时，选择按钮在展开图标左侧也显示实心小盾。折叠侧栏时，小盾替换工作区文件夹图标。待审批优先于运行状态，处理完审批后恢复运行或未读提示。当前工作区无待处理状态时恢复勾选，未读状态独立保留。开启系统减少动态效果时不播放循环动画。

已读状态按浏览器标签页保存。只有对应会话在前台、窗口有焦点且聊天处于最新位置时才确认已读。打开工作区下拉框不会清空未读。会话行以标题字重标记未读，以实心小盾标记等待交互。后台审批不弹窗，进入对应会话后使用原有审批弹窗，不新增审批控制面板。

Web 与 Desktop 的 Bash 审批共用结构化展示。工作目录和原因弱化显示，命令使用现有 Prism 高亮，策略要求确认的命令和写入目标单独强调。长命令默认预览前 240 个 Unicode 字符、最多 4 行，通过现有 shadcn `Collapsible` 和 `Button` 展开完整内容，沿用项目的折叠动画与减少动态效果设置。预览裁剪不修改命令，敏感操作列表不随主命令折叠。待确认单元与完整命令完全相同时，只展示一次代码，下方保留确认提示和原因。仅预览相同的不同命令不合并。展开不会提交审批，批准后仍执行原始完整命令。Bash 审批不额外显示底部的“取消 / 拒绝”按钮，通过 `Deny` 或 `Esc` 拒绝。

下拉列表中的工作区可点击行末移除按钮，再点对钩确认。移除会永久删除该工作区的全部会话文件并移除列表入口，保留项目目录和文件，不写入移除标记或删除日志。失效目录标记“目录不存在”，不能切换但仍可移除。启动目录、当前工作区以及包含运行中、待确认或未读会话的工作区不提供移除入口。

侧栏仅展示当前工作区的会话，按修改时间从新到旧连续排列，不按日期分组，也不限制为六条。搜索框筛选当前工作区的全部会话标题，不搜索消息正文。新建会话位于搜索框旁。`/resume` 打开全部工作区的分组列表。

文件树按目录逐层加载，目录优先、名称排序，支持方向键导航。Git 忽略项仍可浏览和引用，以较暗的颜色显示，仅隐藏 `.git` 内部元数据。分支、变更数量和行末状态均来自工作区 Git 状态，不代表当前会话独自产生的修改。文件区标题行依次提供折叠入口、分支名、变更数量按钮、刷新和折叠全部目录。点击变更数量切换为按相对路径平铺的变更列表，包含已删除项，忽略项不计入变更。非 Git 目录正常浏览。文件与 Git 信息在工作区切换、任务结束、窗口返回前台或手动刷新时更新，不持续监听磁盘。

点击文件在右侧打开单个“文件”标签，后续点击替换预览。切换到会话信息再返回时保留预览及阅读位置，关闭文件返回之前的会话信息标签。预览只读，支持 UTF-8 文本、常用栅格图片和统一差异，已暂存与未暂存差异分开显示。有变更时默认展示差异，可切换到内容。文件名、内容与差异切换、自动折行、引用和关闭集中在标题行，不另开预览弹窗。内容和差异默认自动折行，关闭后允许横向滚动。正文使用同一个横纵滚动视口，横向滚动条位于视口底部，无需先滚到文件末尾。“引用文件”将 `@路径` 插入草稿，不自动发送。浏览不向模型上下文添加内容。预览限制为 512 KiB，二进制、非 UTF-8 文本和超限文件显示说明。文件浏览与预览限制在当前工作区内，拒绝通过符号链接访问外部文件。首版不提供文件编辑或 Git 写操作。

点击历史会话同时恢复对应工作区和消息。跨工作区恢复保留项目信任确认，运行任务期间仍可切换或新建会话。工作区选择优先返回该页面上次查看的会话。工作目录或会话文件已删除时显示错误，不创建替代会话。

会话和工作区列表的行末按钮通过 Grid 同格叠放在列表项上层，不单独占列或挤压文字。按钮在悬停或键盘聚焦时显示，触屏始终显示，操作区使用不透明背景遮挡下方文字。会话行提供重命名、删除按钮。名称原位编辑，Enter 或失焦保存，Esc 取消，空名称不保存，与聊天顶栏一致。重命名非当前会话不会切换会话。删除按钮第一次点击变成对钩，第二次点击才删除，不打开弹窗。失焦或 Esc 取消待确认状态。Ctrl+点击删除跳过确认，但仍执行目录边界、文件身份和运行状态检查。工作区不提供二级菜单，移除会删除该工作区的会话记录。删除不进入回收站，无法撤销，TUI 中的对应历史也会消失。只删除共享历史中的普通会话文件，不删除项目目录、代码、配置，也不清理独立的输入历史、导出文件或遥测记录。

删除当前会话后，查看它的页面在同一工作区进入新会话。运行中、等待交互或未读会话不显示删除按钮，读取最新结果后才恢复删除入口。不限制删除其他空闲且已读的会话。其他页面正在使用的工作区不能移除。客户端根据后端实际删除结果清理草稿、附件、阅读和折叠记忆。扩展否决时不清理，批量部分失败时只清理已删除项，迟到上传和发送失败回调不能重新创建已删除记录。删除准备期间发现会话文件被其他进程修改时会停止删除。删除前应关闭其他 TUI 中正在使用这些会话的窗口，GUI 无法阻止外部进程继续写入。

历史索引独立于流式快照传输。启动、重连、会话切换、重命名及回复结束时更新。窗口回到前台或页面恢复可见时重新读取，也可点击刷新图标获取 TUI 在外部新增、改名或删除的会话。不持续监听目录，也不随每个流式片段扫描磁盘。

侧栏“模型”和 `/model`、`/scoped-models` 打开同一个悬浮窗。可搜索模型、勾选或移出已选模型、调整顺序，也可直接切换当前模型。勾选和排序仅影响当前会话，点击“保存模型”后写入与 TUI 共用的 `enabledModels` 配置，重启后恢复。直接切换不修改默认模型或已选列表。

输入框的模型与思考级别使用基于 Radix 的 shadcn Select，与其他浮层共享磨砂表面。悬停和展开时显示中性高亮底色、边框和较深文字，选项以勾选标识当前值。支持方向键、字符定位和 Esc 关闭，关闭后焦点返回选择器。模型菜单底部的“管理模型”先收起菜单，再打开与左侧栏“模型”按钮相同的悬浮窗，不切换当前模型。没有可选模型时仍可通过该入口添加模型。

输入框只显示当前可用的已选模型，并保持配置顺序。没有已选模型时禁用下拉列表，提示在侧栏选择。当前模型未加入已选列表时只展示名称，不将它追加到候选项，也不退回全部模型。

菜单和会话信息标签页支持键盘导航。悬浮窗限制焦点范围，会话信息栏不阻止聊天操作。`Esc` 关闭最上层的提示、菜单或悬浮窗。悬浮窗关闭后焦点返回输入器，嵌套悬浮窗则返回上一层。审批弹窗点击背景不会关闭，`Esc` 表示取消或拒绝。

每条实际进入对话的用户消息开启一个处理阶段，模型输出分为“处理过程”和正文。处理过程包含多轮思考、工具调用和中途正文。当前阶段执行或重试时默认展开，确认最终回复、下一条用户消息进入对话，或执行结束、停止、失败时自动收起一次。消息仍在队列中、单次工具完成或等待重试都不会触发收起。历史中的非活跃阶段默认收起，纯文字回复不显示空的过程入口。

执行期间手动收起，不因后续输出重新展开。退出实时追踪时仍会自动收起一次，之后手动展开不会被后续阶段再次收起。正常结束的模型消息由后续用户消息接续且没有最终正文时，显示“已接续”，不冒充完成。模型返回空消息、输出截断、工具结果缺失或工具中止不视为正常接续。失败、停止和未完成状态及错误保留在折叠区外。

有阶段标记时按标记识别最终正文。没有标记时，先实时展示最后一条模型消息尾部的正文，后续出现工具或新模型消息时将旧正文归回过程，等该条回复正常结束再确认最终正文。停止或失败时保留已生成的部分，不标为完成。

思考默认折叠。每次工具调用的参数、执行中输出和最终结果合并在同一个可展开操作行中，成功和失败都默认收起，失败时仍展示错误摘要，手动展开的详情保持展开。子级展开状态不随流式更新或整体折叠重置。上翻阅读或手动展开详情时不强制滚动到底部，可点击“回到最新”继续跟随。

文件读取展示行号和语法高亮，搜索按文件展示片段，编辑和写入展示 diff，Bash 展示命令与纯文本日志。参数按字段和列表呈现，JSON 收在“原始数据”中。外部扩展工具使用通用参数与输出布局。代码块使用 `react-syntax-highlighter` 的 Prism 轻量构建，支持复制和常用语言高亮，未注册语言按纯文本显示。

网页搜索展示标题、域名和摘要卡片，网页读取提供可展开预览、返回范围及续读偏移。仅取得部分静态内容时明确提示。卡片不额外抓取网页或加载远程缩略图，链接通过浏览器新页或桌面默认浏览器打开。源码预览按代码显示，网页 HTML 不执行。

子代理执行时默认展开任务列表，显示并行或串行模式、已结束任务数、各任务状态及最新活动。任务详情包含输出、执行记录、耗时和结果文件路径。同名代理按任务顺序分别展示，失败、停止和未执行不会标为成功。任务的手动展开状态在流式更新和整体折叠后保留。`/run` 面板使用相同的进度视图，可停止整批命令任务。

组件源码位于 `src/gui/ui/components/ui/`，选型配置位于 `components.json`。`theme/palette.ts` 生成语义颜色，`theme.css` 将颜色映射到组件并管理材质、字号、间距和圆角的共享变量，`style.css` 管理布局，`transcript.css`、`tools.css`、`rich-tools.css` 和 `code.css` 分别管理对话、工具、网页与子代理、代码样式。

## 实现边界

- `src/gui/host/` 创建和绑定 SDK runtime，处理图形交互、生命周期及输入校验。会话、队列、压缩、重试和工具执行仍由 SDK 管理。
- `src/gui/contract.ts` 只定义跨边界操作参数与可序列化的界面数据，不提供新的 Agent 或 Session 门面。
- `src/gui/ui/` 不导入 Node、Bun 或 SDK 的运行时代码。消息中的 HTML 不执行，远程图片不自动加载。
- GUI 产物启动的子代理通过 `PI_SUBAGENT_CHILD` 进入 `src/harness/runtime/headless.ts`，复用上游 CLI JSON 执行能力并只装配业务扩展，不导入 TUI 入口。Desktop 子代理使用 Electron 的 Node 模式，仍沿用子进程环境变量白名单。
- `src/desktop/` 提供隔离的 Electron 宿主、限定的 preload 桥接、目录选择和文件保存。渲染进程没有 Node 权限。
- `src/web/` 提供静态资源、来源校验和状态订阅。免登录，仅用于可信局域网，TLS 可选。
- `harness` 的呈现器由宿主注入。TUI 呈现器仍只在 TUI 模式使用，GUI 不加载它们。

当前 SDK 没有 `gui` 模式标识。GUI 绑定 `mode: "print"` 和真实 `uiContext`，SDK 据此提供 `hasUI: true`。这不调用 `runPrintMode()`，也不使用 RPC。扩展应通过 `hasUI` 判断标准对话能力，通过 `mode === "tui"` 判断终端组件能力。

支持外部 TS/JS 扩展的工具、命令和标准对话接口。不支持把 `ctx.ui.custom()`、终端编辑器、终端输入监听或终端组件工厂转换为网页。TUI 动效、主题、布局和快捷键不逐项复刻。统计、遥测和复杂工具详情使用图形组件，不保证与 TUI 相同的视觉呈现。

MVP 不承诺任意外部扩展都能在 GUI 使用，尤其是直接依赖终端模式判断、同步编辑器状态或终端组件的扩展。也不承诺任务在应用退出、服务进程重启后继续执行。
