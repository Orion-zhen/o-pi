# GUI MVP

Desktop 和 `opi-web` 共用 React 界面及 SDK 装配。Desktop 在 Electron utility process 中直接调用 `pi-coding-agent`，不启动 Pi CLI、TUI 或 stdio RPC。Web 后端使用 Bun，浏览器通过同源 HTTP 操作和 WebSocket 状态订阅连接。

## 启动

需要 Bun >= 1.4.0。首次安装会下载 Electron。

```sh
bun install --no-save

# 独立 Web 可执行文件
bun run build:web
./dist/opi-web --cwd /path/to/project

# 只构建桌面应用目录，直接预览
bun scripts/build-desktop.mjs --dir
bun run desktop

# 当前系统的桌面分发包
bun run build:desktop
```

Windows 的 Web 产物为 `dist/opi-web.exe`。Desktop 分发文件位于 `dist/desktop/release/`，Linux 为 AppImage，macOS 为 DMG，Windows 为 NSIS 安装程序。MVP 未配置签名、macOS 公证或自动更新。三平台分别构建，不把 Linux 构建成功视为其他平台已经验证。

`bun run dev:web` 构建前端后从源码启动 Web 服务，不提供热更新。

两个分发产物都包含 SDK 和所需运行资源，不要求用户安装 Bun、Node.js 或仓库依赖。Bash、Git、语言服务器等外部工具仍按使用场景由用户安装。Desktop 不需要另外安装 `opi-web` 或 `opi`。

沿用 `~/.pi/agent` 的配置、认证和会话，支持用 `PI_CODING_AGENT_DIR` 覆盖该目录。GUI 直接读取共享 `sessions/` 下各工作区的历史，无需导入或迁移。Web 读取的是后端电脑上的数据，不是访问网页的手机或电脑的本地目录。

Web 内嵌资源使用与 CLI 相同的内容寻址缓存。输入历史与 TUI 共用 `~/.pi/cache/user-history/history.jsonl`，按工作目录隔离。

## Web 访问与手机

默认监听 `0.0.0.0:3141`，无需登录或访问密钥。本机打开 `http://127.0.0.1:3141/`，其他设备打开 `http://电脑的局域网IP:3141/`，并确保防火墙允许该端口。仅本机使用时可指定 `--host 127.0.0.1`。

所有能连接该端口的设备都能控制后端电脑上的文件和进程。仅用于可信局域网，请勿暴露到公网。同源校验不代替身份认证。

浏览器刷新、断网或手机锁屏不结束后台任务。重连后读取 SDK 当前状态和尚未处理的审批，不自动重发操作。

TLS 可选：

```sh
./dist/opi-web --cwd /path/to/project --host 0.0.0.0 --port 3141 \
  --cert /path/to/cert.pem --key /path/to/key.pem
```

使用 TLS 时，通过 `https://电脑的局域网IP:3141/` 或证书对应的域名访问。证书需要被设备信任，并匹配访问地址。当前没有可信反向代理配置，不接受代理转发的协议头。

当前是单用户、单活动会话的宿主。多个页面操作同一会话，审批响应只消费一次。不是多用户服务，也不是每个浏览器各有一份独立会话。

## 界面

界面使用 shadcn/ui 和 Lucide，主布局使用 CSS Grid/Flex。桌面左栏可折叠为图标栏，窄屏左栏使用抽屉，切回桌面宽度时自动关闭。右侧会话信息栏与聊天区分屏，窄屏改为上下排列，各区域独立滚动。分屏和居中悬浮窗使用弹性布局与相对尺寸，不通过绝对定位排列。

配色、磨砂层次、字体与间距、组件状态及响应式布局约束统一记录在 [GUI 设计语言](../DESIGN.md)。

聊天顶栏的“会话操作”菜单提供系统提示词、命令帮助、导入和导出。设置、认证、模型、套餐用量与重载资源按此顺序位于左栏底部。输入框底部的工具按钮显示启用数量，点击打开工具配置。模型、工具、设置、认证、系统提示词和命令帮助均使用悬浮窗。欢迎页的快捷入口只填入草稿，不自动发送。

会话信息栏默认展开，包含会话树、会话统计和遥测。三个页面随会话变更自动更新，流式变更合并读取，不提供手动刷新。顶栏按钮可收起或展开，收起后保留所选标签。切换会话时默认展开，打开悬浮窗不会关闭会话信息栏。

点击会话树的消息正文可定位聊天位置，自动展开所在处理过程。旧分支和已压缩消息在聊天区只读预览，不改变活动分支，点击“返回当前会话”退出预览。树中的切换、总结后切换、创建分支和标签按钮仍执行对应 SDK 操作。

界面按钮发送类型化的 GUI 操作，后端直接调用 SDK 接口或已注册的处理函数，不模拟斜杠输入，不写入输入历史。手动输入斜杠命令仍走原有流程。

左栏顶部并排显示工作区选择和新建会话按钮。工作区下拉框支持路径筛选，先列出启动目录，再列出历史中的不同工作区。桌面端“选择目录”打开系统目录选择器，Web 端打开服务端目录浏览弹窗，支持输入路径、返回上级和筛选子目录，不上传浏览器本机目录。

下拉列表中的工作区可点击行末移除按钮，再点对钩确认。移除只隐藏列表项，保留磁盘目录和全部历史会话。失效目录标记“目录不存在”，不能切换但仍可移除。启动目录和当前工作区不提供移除入口。移除标记保存在 `~/.pi/agent/gui/removed-workspaces/`，重启后生效，桌面端与 Web 共用。通过“选择目录”或历史会话重新打开工作区会恢复显示。

侧栏仅展示当前工作区的会话。组内按最近活动排序，默认展示至多六条历史会话并保留当前会话，可展开更多。工作区同名时显示路径，完整路径可悬停查看。`/resume` 打开全部工作区的分组列表。

点击历史会话同时恢复对应工作区和消息。跨工作区恢复保留项目信任确认，运行任务期间不可切换。工作目录或会话文件已删除时显示错误，不创建替代会话。

会话和工作区列表的行末按钮通过 Grid 同格叠放在列表项上层，不单独占列或挤压文字。按钮在悬停或键盘聚焦时显示，触屏始终显示，操作区使用不透明背景遮挡下方文字。会话行提供重命名、删除按钮。名称原位编辑，Enter 或失焦保存，Esc 取消，空名称不保存，与聊天顶栏一致。重命名非当前会话不会切换会话。删除按钮第一次点击变成对钩，第二次点击才删除，不打开弹窗。失焦或 Esc 取消待确认状态。Ctrl+点击删除跳过确认，但仍执行目录边界、文件身份和运行状态检查。工作区不提供批量删除或二级菜单，移除工作区不会删除会话。删除不进入回收站，无法撤销，TUI 中的对应历史也会消失。只删除共享历史中的普通会话文件，不删除项目目录、代码、配置，也不清理独立的输入历史、导出文件或遥测记录。

删除当前会话后，在同一工作区进入新会话。运行任务或等待其他交互时不能删除。删除准备期间发现会话文件被其他进程修改时会停止删除。删除前应关闭其他 TUI 中正在使用这些会话的窗口，GUI 无法阻止外部进程继续写入。

历史索引独立于流式快照传输。启动、重连、会话切换、重命名及回复结束时更新。窗口回到前台或页面恢复可见时重新读取，也可点击刷新图标获取 TUI 在外部新增、改名或删除的会话。不持续监听目录，也不随每个流式片段扫描磁盘。

侧栏“模型”和 `/model`、`/scoped-models` 打开同一个悬浮窗。可搜索模型、勾选或移出已选模型、调整顺序，也可直接切换当前模型。勾选和排序仅影响当前会话，点击“保存模型”后写入与 TUI 共用的 `enabledModels` 配置，重启后恢复。直接切换不修改默认模型或已选列表。

输入框的模型与思考级别使用基于 Radix 的 shadcn Select，与其他浮层共享磨砂表面。悬停和展开时显示中性高亮底色、边框和较深文字，选项以勾选标识当前值。支持方向键、字符定位和 Esc 关闭，关闭后焦点返回选择器。模型菜单底部的“管理模型”先收起菜单，再打开与左侧栏“模型”按钮相同的悬浮窗，不切换当前模型。没有可选模型时仍可通过该入口添加模型。

输入框只显示当前可用的已选模型，并保持配置顺序。没有已选模型时禁用下拉列表，提示在侧栏选择。当前模型未加入已选列表时只展示名称，不将它追加到候选项，也不退回全部模型。

菜单和会话信息标签页支持键盘导航。悬浮窗限制焦点范围，会话信息栏不阻止聊天操作。`Esc` 关闭最上层的提示、菜单或悬浮窗。悬浮窗关闭后焦点返回输入器，嵌套悬浮窗则返回上一层。审批弹窗点击背景不会关闭，`Esc` 表示取消或拒绝。

每条用户消息后的模型输出分为“处理过程”和正文。处理过程包含多轮思考、工具调用和中途正文，生成时默认展开，确认最终回复后自动收起一次。之后手动展开不会再次自动收起，历史中的已完成过程默认收起。纯文字回复不显示空的处理过程入口。失败、停止和未完成状态保留在折叠区外。

有阶段标记时按标记识别最终正文。没有标记时，先实时展示最后一条模型消息尾部的正文，后续出现工具或新模型消息时将旧正文归回过程，等该条回复正常结束再自动折叠。停止或失败时保留已生成的部分，不标为完成。

思考默认折叠。每次工具调用的参数、执行中输出和最终结果合并在同一个可展开操作行中，成功默认收起，失败展示错误摘要。子级展开状态不随流式更新或整体折叠重置。上翻阅读或手动展开详情时不强制滚动到底部，可点击“回到最新”继续跟随。

文件读取展示行号和语法高亮，搜索按文件展示片段，编辑和写入展示 diff，Bash 展示命令与纯文本日志。参数按字段和列表呈现，JSON 收在“原始数据”中。外部扩展工具使用通用参数与输出布局。代码块使用 `react-syntax-highlighter` 的 Prism 轻量构建，支持复制和常用语言高亮，未注册语言按纯文本显示。

网页搜索展示标题、域名和摘要卡片，网页读取提供可展开预览、返回范围及续读偏移。仅取得部分静态内容时明确提示。卡片不额外抓取网页或加载远程缩略图，链接通过浏览器新页或桌面默认浏览器打开。源码预览按代码显示，网页 HTML 不执行。

子代理执行时默认展开任务列表，显示并行或串行模式、已结束任务数、各任务状态及最新活动。任务详情包含输出、执行记录、耗时和结果文件路径。同名代理按任务顺序分别展示，失败、停止和未执行不会标为成功。任务的手动展开状态在流式更新和整体折叠后保留。`/run` 面板使用相同的进度视图，可停止整批命令任务。

组件源码位于 `src/gui/ui/components/ui/`，选型配置位于 `components.json`。`theme.css` 管理颜色、材质、字号、间距和圆角的共享变量，`style.css` 管理布局，`transcript.css`、`tools.css`、`rich-tools.css` 和 `code.css` 分别管理对话、工具、网页与子代理、代码样式。

## 功能

| 功能 | MVP 入口 |
| --- | --- |
| 对话、思考、工具参数、结果、执行中输出、图片 | 主对话区，内容可折叠 |
| 停止、steer、follow-up、清空队列 | 输入区及队列区域 |
| 新建、恢复、重命名、删除、分支、树导航与标签 | 侧栏、行末按钮、会话树、`/name` |
| JSONL 导入、JSONL/HTML 导出 | 顶栏“会话操作”，Desktop 使用原生保存对话框 |
| 模型、已选模型、思考级别 | 侧栏“模型”、输入区、`/model`、`/thinking`、`/scoped-models` |
| API Key、OAuth 登录和退出 | 认证面板，使用 SDK 的登录交互 |
| 自动压缩、重试、队列和图片设置 | 设置面板，完整设置可编辑 `settings.json` |
| 手动压缩、资源重载 | `/compact`、左栏重载按钮、`/reload` |
| 项目信任、工具审批、确认、选择、输入、多行编辑 | 图形弹窗，不默认批准 |
| 工具启停、分支恢复、保存用户默认 | 输入框底部工具按钮、`/tools` |
| 系统提示词、会话统计、用量、遥测 | 顶栏菜单、右侧标签页、左栏用量按钮，保留 `/system`、`/stats`、`/usage`、`/telemetry` |
| 技能、提示词模板、其他业务扩展命令 | SDK `prompt()` 分发，命令与参数补全 |
| 子代理 | `subagent` 工具、`/agents`、`/run`，图形进度与取消 |
| 上下文裁剪、LSP、Presence、o-pet | 原有 harness 业务与命令 |
| 用户 Shell | `!`、`!!`，执行语义与 SDK/TUI 一致 |
| 文件引用、上传、粘贴图片 | `@路径`、附件按钮、剪贴板 |
| 输入历史 | 输入区历史图标菜单，与 TUI 共用持久记录 |

发送使用按钮或 `Ctrl/⌘ + Enter`。`Enter` 保留换行。输入 `@路径前缀` 后按 `Tab` 获取后端目录候选。上传单文件暂限 3 MB，最多 8 张图片。后端 `@` 附件暂限 8 MiB，二进制附件提供路径供文件工具读取。

`!`/`!!` 是用户直接执行 Shell，不走模型工具的 Approval Gate，与现有 TUI 行为一致。

## 实现边界

- `src/gui/host/` 创建和绑定 SDK runtime，处理图形交互、生命周期及输入校验。会话、队列、压缩、重试和工具执行仍由 SDK 管理。
- `src/gui/contract.ts` 只定义跨边界操作参数与可序列化的界面数据，不提供新的 Agent 或 Session 门面。
- `src/gui/ui/` 不导入 Node、Bun 或 SDK 的运行时代码。消息中的 HTML 不执行，远程图片不自动加载。
- GUI 产物启动的子代理通过 `PI_SUBAGENT_CHILD` 进入现有 CLI JSON 执行入口，不再启动 GUI 宿主。Desktop 子代理使用 Electron 的 Node 模式，仍沿用子进程环境变量白名单。
- `src/desktop/` 提供隔离的 Electron 宿主、限定的 preload 桥接、目录选择和文件保存。渲染进程没有 Node 权限。
- `src/web/` 提供静态资源、鉴权、来源校验和状态订阅。监听非回环地址时必须启用 TLS。
- `harness` 的呈现器由宿主注入。TUI 呈现器仍只在 TUI 模式使用，GUI 不加载它们。

当前 SDK 没有 `gui` 模式标识。GUI 绑定 `mode: "print"` 和真实 `uiContext`，SDK 据此提供 `hasUI: true`。这不调用 `runPrintMode()`，也不使用 RPC。扩展应通过 `hasUI` 判断标准对话能力，通过 `mode === "tui"` 判断终端组件能力。

支持外部 TS/JS 扩展的工具、命令和标准对话接口。不支持把 `ctx.ui.custom()`、终端编辑器、终端输入监听或终端组件工厂转换为网页。TUI 动效、主题、布局和快捷键不逐项复刻。统计、遥测和复杂工具详情使用图形组件，不保证与 TUI 相同的视觉呈现。

MVP 不承诺任意外部扩展都能在 GUI 使用，尤其是直接依赖终端模式判断、同步编辑器状态或终端组件的扩展。也不承诺任务在应用退出、服务进程重启后继续执行。

## 验证

```sh
bun run typecheck
./node_modules/.bin/vitest run tests/gui
bun run test:gui
```
