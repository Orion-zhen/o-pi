# 工作区与文件

工作区选择器决定左栏会话和文件范围。Desktop 使用系统目录选择器，Web 使用服务端目录浏览器。启动目录和历史工作区都可选择。

## 文件与 Git

文件树逐层加载，目录优先并按名称排序。Git 忽略项可以浏览和引用，颜色较暗。`.git` 内部元数据隐藏。

变更列表包含已删除文件，区分暂存与未暂存状态。信息在工作区切换、任务结束、窗口回到前台和手动刷新时更新。

点击文件打开右侧预览，后续文件替换当前预览。“引用文件”将 `@路径` 插入草稿。预览限制在工作区内，符号链接不能指向外部文件。

## 文本

支持 512 KiB 以内的 UTF-8 文本和统一差异。存在差异时优先显示差异，可切换为正文。文本默认折行，可关闭折行后横向滚动。

## 图片

支持 PNG、JPEG、GIF、WebP 和 SVG。图片默认适应窗口，小图保持原尺寸。提供实际大小、适应窗口、拖动、滚轮缩放和键盘移动。

缩放按钮与滚轮按 5% 档位移动，手动输入支持 1%–3200%。百分比输入可带 `%`，Enter 或失焦应用，Esc 取消。SVG 通过独立图片资源加载。

## PDF

PDF 默认适应宽度并连续滚动，支持页码跳转、适应整页、缩放、文字选择和复制。Ctrl/⌘+滚轮按 5% 档位缩放，PageUp/PageDown 翻页。手动缩放范围为 10%–800%。

阅读器挂载可视页及相邻页，最多同时渲染两页。每页画布上限为 800 万像素或单边 8192 像素。扫描件按图像显示，加密文档需先解密。

## 资源传输

图片和 PDF 按资源地址流式读取，地址绑定客户端、工作区和文件版本。Web 与 Desktop 共用 Range 和版本检查，PDF.js 按需读取分段。字体、CMap、Worker 和 WASM 随应用打包。

图片与 PDF 没有文件字节数门槛，实际打开能力取决于解码内存和文件结构。超大像素图片仍由浏览器解码原图。

刷新未变化文件时复用资源地址和阅读状态。PDF 更新后保留缩放和有效页码。切换或关闭预览时释放资源。

## 移除工作区

移除操作删除该工作区的全部会话文件，保留项目文件。启动目录、当前工作区、其他页面正在使用的工作区，以及包含运行、待确认或未读会话的工作区受到保护。

移除始终需要二次确认。失效目录仍可移除其历史入口。
