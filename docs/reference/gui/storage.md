# 存储管理

“设置 → 系统与扩展 → 存储管理”统计后端电脑上的全局会话、输入历史、遥测、离线报告、程序资源缓存、工具临时文件和 SDK 日志。Desktop 还提供 Electron HTTP 缓存和 GUI 诊断日志。

## 扫描

分类可展开、搜索和多选。显示大小来自文件元数据，读取失败时标记统计不完整。扫描不跟随条目内的符号链接。

应用写入位置和扫描共用 `src/harness/storage/paths.ts`。会话使用 SDK 实际目录，Desktop 使用 Electron 目录与缓存 API。

## 删除

删除立即生效，不经过回收站。清理前等待所有任务结束，并关闭其他 Pi / opi 实例。

以下内容受保护：

- 当前打开的会话。
- 当前程序资源和正在记录的遥测。
- MCP 当前日志和 GUI 当前诊断日志。
- 最近 24 小时的工具临时文件。

配置、凭据、扩展安装文件和项目文件不参与清理。旧工具输出删除后，历史消息中的文件链接可能失效。

删除只接受最近一次扫描生成的标识，并复核目录、文件身份和修改时间。文件变化时需要刷新。批量删除中途失败后，刷新列表确认剩余内容。

输入历史清理与写入共用文件锁，诊断日志清理与轮转共用队列。Desktop 的缓存清理只处理 HTTP 缓存，保留布局和登录状态。
