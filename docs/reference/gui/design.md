# GUI 设计规范

适用于 Web 与 Desktop。界面以正文阅读为中心，用留白组织内容，用底色表示状态，用弱分隔线划分区域。

## 配色

浅色使用中性浅灰，深色使用炭灰。主题色默认 `#007AFF`，用于主要操作、链接、焦点和少量选中标识。成功、警告和错误保留独立语义色。

深色基础底为 `#18181A`，顶栏 `#1D1D1F`，侧栏 `#242426`，输入器与浮层 `#2C2C2E`，控件薄填充使用 `#444446`。原生窗口与页面共用 `src/gui/theme-base.ts`。

`preferences/palette.ts` 使用 OKLab 混色与对比度校正生成语义颜色。组件通过 `preferences/theme.css` 的变量取色。代码高亮和差异保留语义配色。

## 表面

| 区域 | 表现 |
| --- | --- |
| 聊天画布 | 较厚、连续的内容表面 |
| 侧栏与顶栏 | 较轻的磨砂 |
| 输入器 | 较实的底色、圆角和轻阴影 |
| 菜单与小弹窗 | 浮层材质和柔和阴影 |
| 大弹窗 | 标题与导航使用磨砂，长表单使用稳定底色 |
| 文件正文 | 稳定阅读底色 |
| 统计分组 | 薄填充、留白和横向弱分隔线 |

每个大区域使用一个材质承载层。子级通过透明背景或薄填充组织内容，避免叠加多层模糊和阴影。

材质值由 GUI 配置统一驱动。平台差异和系统透明度设置见[配置](configuration.md#材质)。

## 字体与尺寸

界面使用系统无衬线字体，代码与技术标识使用等宽字体。用户可配置字体链和基准字号。

共享字号从辅助信息、紧凑控件、界面正文、聊天正文到标题逐级增大。字重以 400、500、600 为主。间距使用 `--space-*`，圆角使用 `--radius-*`。具体尺度以 `theme.css` 为准。

控件由内容、字体和内边距决定尺寸。长标题允许换行，区域可用相对尺寸上下限约束阅读宽度和滚动范围。

## 布局与交互

- 主体采用 Flex、Grid 和文档流，窄屏通过换行、堆叠或抽屉重排。
- 同类元素共享字号、间距、圆角和状态样式。
- 主要操作使用实心按钮，次级操作使用描边按钮，工具操作使用无底色按钮。
- 图标按钮提供可访问名称，Tooltip 使用短动作或状态。
- 选中、悬停、按下、焦点和禁用分别表达。
- 弹窗管理焦点，关闭后返回原操作位置。
- 菜单锚定和避让交给 Radix。
- 消息补全在输入器内部展开，沿用输入器表面。
- 长命令、参数和列表通过展开查看。

虚拟列表、PDF 文字层和图片缩放可以按自身需求使用定位与测量。

## 动效

CSS 时长与曲线位于 `app/motion.css`，Motion 预设位于 `lib/motion.ts`。同一属性由一种动画机制控制。

交互反馈约 120ms，淡入淡出约 160–180ms，布局与折叠约 280ms。使用单调减速曲线或 `bounce: 0` 的阻尼动画。拖动直接跟手，折叠可在途中反向操作。

退场内容先停止交互，再卸载。折叠保留子级状态，流式更新保留手动展开状态。会话切换按内容区域淡入淡出。

循环装饰和列表动效遵循已接入的系统减少动态效果设置。欢迎页空闲动画在窗口失焦、隐藏或用户操作时停止。

## 检查

- 深浅色和自定义主题色下的可读性。
- 宽屏、窄屏、短窗口和窄容器中的布局。
- 根字号放大到 200% 及单独调整 GUI 字号后的操作可达性。
- 长标题、模型名、错误信息和代码的换行与滚动。
- 键盘焦点、弹窗焦点恢复和触屏入口。

需要页面验证时使用定向无头测试，见[测试](../runtime/testing.md)。
