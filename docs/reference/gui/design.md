# GUI 设计规范

适用于 Web 与 Desktop。界面以正文阅读为中心，用留白组织内容，用底色表示状态，用弱分隔线划分区域。

## 配色

浅色使用中性浅灰，深色使用炭灰。主题色默认 `#007AFF`，用于主要操作、链接、焦点和少量选中标识。成功、警告和错误保留独立语义色。

深色基础底为 `#18181A`，顶栏 `#1D1D1F`，侧栏 `#242426`，输入器与浮层 `#2C2C2E`，控件薄填充使用 `#444446`。原生窗口与页面共用 `src/gui/shared/theme.ts`。

`frontend/ui/theme/palette.ts` 使用 OKLab 混色与对比度校正生成语义颜色。组件通过 `frontend/ui/theme/theme.css` 的变量取色。代码高亮和差异保留语义配色。

## 表面

| 区域 | 表现 |
| --- | --- |
| 聊天画布 | 较厚、连续的内容表面 |
| 侧栏与顶栏 | 较轻的磨砂 |
| 输入器 | 较实的底色、圆角和轻阴影 |
| 菜单与小弹窗 | 浮层材质和柔和阴影 |
| 大弹窗 | 标题与导航使用磨砂，长表单使用稳定底色 |
| 文件正文 | 稳定阅读底色 |
| 统计分组 | 薄填充、留白和横向弱分隔线 |

每个大区域使用一个材质承载层。子级通过透明背景或薄填充组织内容，避免叠加多层模糊和阴影。

材质值由 GUI 配置统一驱动。平台差异和系统透明度设置见[配置](configuration.md#材质)。

## 字体与尺寸

界面使用系统无衬线字体，代码与技术标识使用等宽字体。用户可配置字体链和基准字号。

共享字号从辅助信息、紧凑控件、界面正文、聊天正文到标题逐级增大。字重以 400、500、600 为主。间距使用 `--space-*`，圆角使用 `--radius-*`。具体尺度以 `theme.css` 为准。圆角统一使用原生 CSS `corner-shape: superellipse(1.3)`，圆形与 `rounded-full` 胶囊保留 `round`。不支持该属性的浏览器保留普通圆角。SVG 图形不受此规则影响。

控件由内容、字体和内边距决定尺寸。长标题允许换行，区域可用相对尺寸上下限约束阅读宽度和滚动范围。

## 布局与交互

- 主体采用 Flex、Grid 和文档流，窄屏通过换行、堆叠或抽屉重排。
- 同类元素共享字号、间距、圆角和状态样式。
- 主要操作使用实心按钮，次级操作使用描边按钮，工具操作使用无底色按钮。
- 图标按钮提供可访问名称，Tooltip 使用短动作或状态。
- 选中、悬停、按下、焦点和禁用分别表达。
- 弹窗管理焦点，关闭后返回原操作位置。
- 菜单锚定和避让交给 Radix。
- 消息补全在输入器内部展开，沿用输入器表面。
- 长命令、参数和列表通过展开查看。

虚拟列表、PDF 文字层和图片缩放可以按自身需求使用定位与测量。

## 反馈

- 结果已在界面可见时不重复通知。主动取消静默结束。
- 保存、校验和加载失败留在对应操作区域。持续问题使用状态条，修复后消失。
- 无合适归属的短反馈使用 Toast。重复项合并，同时最多一条。仅存在于 Toast 的错误不自动消失。
- Toast 在标题栏下方、会话内容区顶部居中，图标与操作垂直居中。宽度随内容伸展，空间不足时才换行。多行消息仅预览原文首行，后续内容在通知内展开，空间足够时详情入口与摘要同行。查看详情不阻止继续操作界面。
- 命令结果和会话诊断留在时间线，不重复弹出通知。使用“通知 (数量)”分组，收起只显示组标题，展开后完整显示等宽原文和弱分隔线。错误和警告全文使用对应语义色，不加图标、摘要或二次折叠。
- 仅审批和必须立即决定的高风险操作使用模态对话框，保留完整详情和明确选项。系统通知只在应用不在前台时发送，不展示会话正文、名称、命令或错误正文。
- 面向高级用户和开发者，操作状态使用中文，系统、SDK 和服务端错误保留原文、错误码、路径与字段名。必要时补充操作上下文，不重复翻译或猜测原因。
- 内联运行反馈默认预览最多三行，按实际排版判断溢出，不按字符数或首行截断。仅长内容折叠。所有详情保留完整原文，可选择和复制。
- 校验错误在对应字段旁完整展示，不重复汇总全文。折叠分组标明存在待修复项，无对应控件的问题保留明确的修复入口。
- 时间线通知以外的反馈使用中性底色和弱分隔，警示色集中于图标或短状态，不将诊断全文染色。普通文字用界面字体，代码、路径和展开的日志使用等宽字体。保留必要动作，不添加无意义的确认。
- 动效保持轻微，不抢焦点，不反复吸引注意。信息完整性与视觉强调程度分开控制。
- 反馈区域使用 Flex、Grid 和文档流。浮层采用 Grid 叠层，不手写绝对定位或固定尺寸。

## 动效

变化都有入场、更新和退场过渡，复用现有组件与预设。不手写动画驱动，不新增系统减弱动态效果处理。测试业务行为，不逐帧验证动画。

程序化动画使用 Motion，图标轮廓变形使用 morphicons，直接传入 Lucide 图标数据。优先用现成图标组件与声明式动画，不复制 SVG 路径。一次性高亮由 React 管理挂载和卸载，不手动增删 DOM 属性或样式。CSS 负责简单样式过渡、文字入场、Radix 开合、折叠和纯循环装饰。通用动效预设、时长尺度与曲线定义在 `frontend/ui/motion/transitions.ts`，由 `applyMotionTokens` 写入 CSS 变量。CSS 单段过渡使用这些变量，Tailwind 默认过渡也使用同一来源。同一属性由一种动画机制控制。

### 时长与编排

单段定时动画使用七档。`motionDuration` 以秒供 Motion 使用，CSS 使用对应的 `--motion-duration-*`。

| 档位 | 时长 |
| --- | --- |
| 1 | 120ms |
| 2 | 180ms |
| 3 | 280ms |
| 4 | 400ms |
| 5 | 600ms |
| 6 | 800ms |
| 7 | 1200ms |

档位不绑定用途。动画预设根据变化幅度、辨认需求、注意力转移和操作频率选择时长与曲线，同类动画共享预设，不在组件中另写固定时长。小控件也可以使用长档。思考和速度档位切换共用 400ms 的 `controlShift`，菜单快速退场，换挡继续落定，不额外等待菜单关闭。

多段动画的起点、重叠、错峰和停留按场景编排，总时长自然合成，不要求落在七档上。欢迎页时序集中在 `app/welcome/welcome-timing.ts`。定位高亮按淡入、停留、淡出编排，不作为一段长过渡压缩。笔画序列、触发延迟和循环周期独立管理，不套用七档。

使用单调减速曲线或 `bounce: 0` 的阻尼动画。物理参数驱动的弹簧保留自身的稳定时间，不为凑档截断。拖动直接跟手，折叠可在途中反向操作。即时更新可用 0ms，不另设档位。

### 交互

状态文字原位交叉淡化，同一位置的状态图标使用 morphicons 的 `smooth` 变形，保持组件挂载，等待时圆环旋转。实心图标的填充写入图形数据，不只设置 SVG 属性。折叠箭头继续使用 CSS 旋转，彩色文件图标保持原样。输入框保留原生 `field-sizing`，由 Motion `resize` 提供尺寸，外层过渡高度，不缩放文字。消息行统一负责入场，正文不叠加整段淡入。当前可见会话的正文与思考按新增文本片段播放一次 120ms 淡入，模糊从 2px 降到 0，不逐字错峰。动画结束后合并回普通文本。会话切换、页面恢复和折叠展开不补播已有内容，代码与公式不参与文字动画。活动标记退出与结束信息展开同步进行。聊天滚动由现有跟随逻辑管理，关闭浏览器自动滚动锚定，避免高度过渡重新触发跟随。

退场内容先停止交互，再卸载。正文块按原始顺序保持父节点与 key，过程与最终回答的分类只改变可见性和样式，不迁移或重挂载正文。折叠保留子级状态，流式更新保留手动展开状态。会话切换按内容区域淡入淡出。应用入场时侧栏外壳保持展开。主区、侧栏内容与各列表在各自首次就绪后独立入场，晚到的数据仍从头播放。列表只编排首批挂载行，从上到下按固定间隔错峰，不按数据总量压缩间隔，也不扣除加载与渲染耗时。最后一行完成后结束本批入场。区域内交互只结束该区域正在播放的入场，不取消其他区域或尚未就绪的入场。刷新、搜索、会话切换和虚拟滚动不重播启动动画。

操作立即生效，动画不阻塞业务。定位高亮在滚动落定后播放。工具完成、附件加入和队列接力只反馈真实变化，历史内容重新挂载时不重播。文件引用成功后，按钮与输入器同步反馈。欢迎卡片的图标仅在悬停或聚焦时播放一次。

欢迎页空闲动画在窗口失焦、隐藏或用户操作时停止。

## 检查

- 深浅色和自定义主题色下的可读性。
- 宽屏、窄屏、短窗口和窄容器中的布局。
- 根字号放大到 200% 及单独调整 GUI 字号后的操作可达性。
- 长标题、模型名、错误信息和代码的换行与滚动。
- 键盘焦点、弹窗焦点恢复和触屏入口。

需要页面验证时使用定向无头测试，见[测试](../runtime/testing.md)。
