# GUI 会话

GUI 从 SDK 的 `sessions/` 目录读取各工作区历史。每个逻辑会话在同一宿主内对应一个 `GuiSession`，客户端独立选择查看位置。

## 消息与队列

输入框默认发送引导消息，可切换为跟进消息。选择在当前界面临时保存。引导消息在下一次可介入时处理，跟进消息等待当前任务结束。

普通停止先清空队列，将引导、跟进消息依次放回操作客户端的输入框，再取消生成。原草稿放在最后。压缩期间的停止只取消压缩，队列继续由 SDK 管理。

用户输入 `!`、`!!` 直接执行 Shell。`@路径` 从后端读取附件，附件上传使用访问设备的文件。上传单文件上限为 3 MB，最多 8 张图片，后端 `@` 附件上限为 8 MiB。

## 展示

每条实际进入对话的用户消息开启一个处理阶段。思考、工具和中途正文组成处理过程，最终正文单独显示。执行或重试时过程默认展开，结束后自动收起一次。手动展开状态在后续更新中保留。

思考与工具详情默认折叠。失败、中止和未完成状态在折叠区外显示。上翻阅读或手动展开详情时暂停自动滚动，点击“回到最新”恢复跟随。

工具结果按类型展示：文件行号、搜索区域、编辑差异、Shell 日志、网页卡片和子代理进度。原始参数保存在可展开区域。远程图片需要用户主动打开，消息中的 HTML 按文本内容处理。

## 分支与历史

会话树的消息定位可以只读查看旧分支和已压缩消息。切换分支、总结后切换、创建分支和标签操作调用 SDK。

聊天历史读取原始分支条目，模型上下文读取 `buildSessionProjection()`。上下文裁剪和替换作用于模型请求，已有聊天展示保持原文。

导入 JSONL 时分配新会话标识。导出支持 JSONL 和 HTML，Desktop 使用原生保存对话框。

## 多客户端

操作携带提交时的目标会话。切换页面订阅、刷新和断线保留后台任务，重连后读取当前状态及待处理审批。一次审批只消费一次。

页面隐藏后接收会话概览，回到前台再订阅当前会话详情。草稿、附件、阅读位置和展开状态在页面内按会话保存，刷新后的保留情况由客户端状态决定。

已读状态按浏览器标签页保存。当会话在前台、窗口有焦点且聊天位于最新位置时确认已读。后台审批显示状态标记，进入目标会话后显示弹窗。

## 实例回收

`GuiSession` 保留身份与授权，可回收的 `GuiExecution` 持有 SDK runtime、执行任务和载荷。

`sessionCache.idleMs` 同时控制空闲门槛和扫描间隔。扫描将已超时且可安全释放的实例按最近使用时间排序，保留 `idleLimit` 个，释放其余实例。默认分别为 60000 毫秒和 3。

运行、排队、等待交互和后台命名期间保活。未超时实例不占保留额度。`idleLimit: 0` 仍需先达到空闲门槛，因此总实例数可以超过该值。

回收保留会话文件和当前宿主内的会话授权，重新打开时加载历史。GUI 保存策略后重设扫描计时器，直接编辑文件后需重启或在 GUI 中重新保存。启动配置无效时使用默认策略。

关闭宿主会取消任务并等待必要写入。

## 重命名与删除

名称原位编辑，Enter 或失焦保存，Esc 取消。删除采用两步确认，Ctrl/Command+点击可直接提交会话删除。

运行中、等待交互或未读会话暂不提供删除入口。删除当前会话后，查看它的页面进入同工作区的新会话。

删除操作检查目录、文件身份和运行状态，发现外部修改时停止。删除直接移除共享历史文件，不经过回收站。外部 Pi 进程仍可能写入，删除前应关闭相关实例。

历史索引在连接、切换、重命名、回复结束和窗口回到前台时更新，也可手动刷新。
