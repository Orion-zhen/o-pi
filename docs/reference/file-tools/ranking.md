# 搜索排序

`find` 按路径匹配质量排序，`grep` 按正文、结构和关系证据排序。两者共用文件系统的范围、glob、可见性和访问策略。

## find

fzf 查询在范围相对路径上执行。动态规划选择得分最高的字符对齐，连续字符、路径段、单词和驼峰边界获得奖励，间隔受到惩罚。

同分时依次比较基础名称命中、匹配跨度、路径长度、范围顺序和路径字典序。

每个候选出现后立即评分，排序器保留有界相关性前缀和各正向 OR 分支的最佳候选。截断时保留前 4 条，再覆盖尚未展示的正向 OR 分支，最后按相关性填满。

参数与语法见 [find](find.md)。

## grep 候选

正文命中生成已验证候选。只有整次扫描无正文命中时，工作区符号或查询词锚点才生成相关候选。

| 来源 | 含义 |
| --- | --- |
| `text-literal` | 显式字面量命中 |
| `text-regex` | 逐行正则命中 |
| `text-lexical` | 零命中后的词法相关结果 |

每个候选最多一个来源。字面量和正则来源排名固定为 1，词法来源按相关性排名，同分共享排名。

```text
sourceScore = sourceWeight / (60 + sourceRank)
```

权重位于 `src/harness/file-tools/grep/ranking.ts`。

## 层级与字段分数

排序键依次为：

```text
查询层级 + 权威等级
-> BM25F 字段分数
-> 来源排名分数
-> 已验证覆盖率
-> 区域大小
-> 路径与行范围
-> 标识
```

查询层级优先精确符号、成员和结构覆盖，再到正文区域、文本行和词法相关结果。每层的权威等级为 `called`、`referenced`、`defined`、`unknown`。

经过快照校验且目标唯一的外部调用形成 `called` 证据，外部引用形成 `referenced` 证据。递归、多目标和间接绑定保留在关系事实中。路径只参与字段匹配和最终同分排序，目录名称不代表代码权威性。

BM25F 字段：

| 字段 | 权重 | 长度归一化 |
| --- | ---: | ---: |
| 叶子符号 | 8 | 0 |
| 限定符号或所有者 | 6 | 0.2 |
| 路径 | 5 | 0.3 |
| 声明或签名 | 3 | 0.5 |
| 命中或证据行 | 1 | 0.75 |

IDF 使用本次合格候选集合。Tree-sitter 补充源码结构和调用位置，LSP 关系提供语义证据。

## 结果选择

先按 `grep_related_result_limit` 限制相关区域，再按总结果上限选择。前 4 条保持纯相关性顺序，剩余名额在同一层级内使用 `lambda=0.85` 的 MMR，减少同文件、同符号和同目录重复。选定后恢复相关性顺序。

`grep_regional_display_limit` 限制单区域展示行数。模型输出不按词元数重排，`approx_tokens` 用于观测。

算法以 `semantic-tier-bm25f-rrf-mmr-v2` 写入遥测，记录候选数量、层级、分数、MMR 替换和文件覆盖。工具结果见 [grep](grep.md)，测量见[基准](../runtime/benchmark.md)。
