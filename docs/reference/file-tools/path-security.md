# 路径与安全

六个文件工具通过文件系统命名空间检查路径。相对路径基于当前调用的 cwd，该目录也是配置选择依据。

## 解析

普通路径支持相对路径、`..`、绝对路径和明确符号链接。文件名中的 glob 字符按原名处理，搜索的 glob 通过独立参数指定。

工作区内路径以相对形式展示，外部绝对路径保持规范化绝对形式，内部统一使用 `/`。

## 受阻路径

blocked_path 同时检查：

1. 按 cwd 解析的字面路径。
2. 符号链接解析后的真实目标。
3. 写入所需的最近现有父目录。

write 和 edit 在队列内重新检查，防止排队期间路径变化。悬空链接继续解析目标位置与父目录。

文件工具允许显式访问工作区外路径，仍受配置和操作系统权限限制。受阻路径无法通过符号链接别名绕过。

## 忽略与访问

软忽略决定自动发现时是否跳过，受阻路径决定能否访问。`.piignore`、`.gitignore` 和 ignored_path 属于软忽略。

明确 read、write、edit 或明确搜索范围可以访问软忽略路径。`.git/` 默认受阻。规则语义见[忽略规则](ignore.md)。

## 符号链接

- ls 在父目录中保留链接条目，直接读取链接目录时跟随目标。
- find 和 grep 递归发现跳过子符号链接。
- read、write、edit 可访问明确给出的链接，通过字面与真实路径检查后执行。

## 技能

技能资源通过 skill:// 挂载，授权来自当前分支记录。逻辑根和真实目标都需在技能范围内，绝对路径和符号链接别名不能绕过加载授权。详见[技能](../skill-context/README.md)。

## 错误处理

目录不存在返回 PATH_NOT_FOUND，read 文件不存在返回 FILE_NOT_FOUND。类型不匹配使用 NOT_A_DIRECTORY 或 NOT_A_FILE，受阻使用 PROTECTED_PATH，权限不足使用 ACCESS_DENIED。

配置错误在工作区访问前返回 CONFIG_ERROR。完整结构保存在 details，模型接收简短错误和可用恢复动作。
