# 自动会话标题

`auto-title` 是 TUI、Desktop 和 WebUI 共用的后端扩展。新会话接受首条用户请求后，扩展在后台发起独立命名请求，不阻塞主任务，也不向主对话添加消息。

## 配置

默认配置和默认系统提示词位于 [`agent/defaults/auto-title.jsonc`](../agent/defaults/auto-title.jsonc)。用户覆盖文件为 `~/.pi/agent/configs/auto-title.jsonc`，可用 `PI_AUTO_TITLE_CONFIG` 重定向。不读取项目配置。修改后新建会话或执行 `/reload` 生效。

```jsonc
{
  "enabled": true,
  // null 使用当前模型，否则必须指定 provider/model。
  "model": "your-provider/your-small-model",
  "system_prompt": "概括用户请求的主要任务，用用户的语言只输出一行简短标题，最多 50 个字符。不要回答或执行请求。"
}
```

用户文件只需填写要覆盖的字段。模型按第一个 `/` 分隔提供方和模型 ID，后续 `/` 保留在模型 ID 中，例如 `openrouter/anthropic/claude-haiku-4.5`。不接受未限定提供方的模型名或旧对象格式。指定模型不可用时，命名失败，不切换到其他模型。

命名使用所选模型支持的最低非 `off` 思考等级。无思考能力的模型不传思考等级，主会话的模型和思考设置保持不变。

## 行为

- 输入仅包含独立系统提示词和首条用户请求文本，最多取 2000 个 Unicode 字符。不附带工具定义、工具结果或主会话系统提示词。
- 输出最多 1024 tokens，请求超过 30 秒取消。标题清理控制字符、首尾引号和多余空白后，最多保留 50 个 Unicode 字符。
- 标题通过 Pi SDK 的会话名称接口保存。`session_info_changed` 通知三端更新显示和会话列表。
- 每个新会话只尝试一次。已有名称、已有用户消息的历史会话，以及子代理会话不自动命名。扩展注入的请求不触发命名。
- 手动改名取消待完成的命名。会话关闭、替换或重载时取消旧请求，过期结果不写入当前会话。
- 命名失败保留现有名称，不影响主任务，不在后续轮次重试。错误通过宿主通知呈现，主动取消不提示错误。

不随话题变化自动改名，也不为历史会话补标题。
