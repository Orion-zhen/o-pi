# GUI 使用指南

Desktop 和 Web 使用同一套界面。启动方式见[安装与启动](getting-started.md)。

## 开始对话

1. 在左栏选择工作区。Desktop 使用系统目录选择器，Web 浏览服务端目录。
2. 通过认证面板登录提供方，或在设置中添加模型服务。
3. 在左栏“模型”中选择常用模型。
4. 输入任务，按 Ctrl/⌘+Enter 发送。

Enter 默认换行，可在“设置 → 对话与输入”中改为 Enter 发送。欢迎页的快捷入口会填入草稿，确认后发送。

输入框底部可以切换模型、思考等级和工具。模型面板中的“保存模型”将已选列表写入全局配置。

## 运行中补充消息

输入框中的发送模式可在“引导”和“跟进”之间切换：

- 引导：在下一次可介入时处理。
- 跟进：当前任务结束后处理。

停止任务会把待发送消息放回当前页面的输入框。压缩期间显示“停止压缩”，此时点击只取消压缩。

## 管理会话

左栏显示当前工作区的会话，搜索框按标题筛选。可以新建、重命名、删除，或用 `/resume` 查找其他工作区的历史。

会话树位于右侧信息栏。点击消息可查看对应位置，切换分支和创建分支使用行内操作。顶栏“会话操作”提供系统提示词、命令帮助、导入和导出。

切换会话和浏览器断线后，后台任务继续运行。草稿、附件和阅读位置在当前页面按会话保存，刷新页面前请保留重要草稿。

会话删除需点击两次确认。Ctrl/Command+点击可跳过会话删除确认。删除会直接移除共享历史，TUI 中的对应记录也会消失。删除前关闭其他正在使用这些会话的 Pi / opi 实例。

## 查看执行过程

每条用户消息对应一个处理阶段。思考、工具和中途输出收在“处理过程”中，最终回复单独显示。点击工具行可展开参数、输出或差异。

上翻阅读时暂停自动跟随，点击“回到最新”继续跟随。失败或中止的提示保留在折叠区域外。

需要审批时，进入对应会话处理弹窗。批准、会话放行和持久放行的含义见[审批模块](../reference/approval-gate/README.md)。

## 浏览项目文件

左栏文件树可以查看目录和 Git 状态。点击文件在右侧预览，点击“引用文件”将 `@路径` 插入草稿。Git 变更列表区分暂存和未暂存内容。

文本支持内容与差异视图。图片支持缩放、拖动和实际大小显示。PDF 支持翻页、缩放和文字选择。预览操作不会把文件内容发给模型。

文件信息在任务结束、工作区切换、窗口回到前台或手动刷新时更新。完整预览规则见[工作区与文件](../reference/gui/workspace.md)。

## 设置与布局

设置页按外观、对话与输入、模型服务、工具与代码、网络与网页、子代理、权限与安全、连接与集成、存储管理、终端界面分类。

修改设置后点击“保存”。切换分类会保留草稿，关闭设置时会提示未保存修改。“放弃修改”恢复已保存值。Desktop Web 设置保存后需要重启 Desktop。

宽屏可拖动左右分隔线、消息区边缘和左栏横向分隔线。双击分隔线恢复该项默认值。布局在当前客户端保存，手机布局使用抽屉和上下分屏。

外观字段见 [GUI 配置](../reference/gui/configuration.md)，存储清理见[存储管理](../reference/gui/storage.md)。

## 通知

在“设置 → 对话与输入 → 系统通知”中开启浏览器通知。Web 通知需要浏览器授权和安全上下文。Desktop 使用系统原生通知。

通知显示会话名，未命名时使用首条用户消息开头。请留意锁屏显示的内容。通知条件见[系统通知](../reference/runtime/notifications.md)。
