# 远程访问

Web 服务免登录，连接者可以操作后端电脑的文件和进程。推荐通过 SSH 隧道访问，局域网直连只用于可信网络。

## 独立 Web 服务

```bash
./dist/web/opi-web --cwd /path/to/project --host 127.0.0.1 --port 19198
```

`opi-web --help` 显示参数和默认值。`-p` 是 `--port` 的简写，端口 `0` 表示自动分配。访问地址以启动输出为准。

独立 Web 使用自己的后端进程。浏览器看到的是服务端的文件、认证和会话。

## Desktop Web

在 Desktop 的“设置 → 连接与集成 → 桌面 Web 访问”中启用，填写监听地址和端口，保存后重启 Desktop。

也可以在用户 `gui.jsonc` 中配置：

```json
{
  "desktopWeb": {
    "enabled": true,
    "host": "127.0.0.1",
    "port": 19198
  }
}
```

浏览器和桌面窗口共用同一个后端，可打开同一会话查看输出、发送消息和处理审批。监听失败时桌面应用会报告错误，仍可继续使用桌面界面。

关闭 Desktop 会结束任务和 Web 服务。浏览器刷新或 SSH 断线只断开客户端。

## SSH 隧道

在访问端电脑运行：

```bash
ssh -N -L 19198:127.0.0.1:19198 user@host
```

随后打开 `http://127.0.0.1:19198/`。SSH 提供认证和加密，服务端保持回环监听即可。

## 局域网直连

将监听地址改为 `0.0.0.0`，在其他设备打开 `http://服务端局域网IP:端口/`。服务端防火墙需允许该端口。不要将端口直接暴露到公网。

## HTTPS

独立 Web 可指定证书和私钥：

```bash
./dist/web/opi-web --cwd /path/to/project --host 0.0.0.0 \
  --cert /path/to/cert.pem --key /path/to/key.pem
```

两个参数必须同时提供。证书需被访问设备信任，并匹配访问地址。Desktop Web 提供 HTTP，可使用 SSH 隧道保护连接。

浏览器通知和本机字体读取需要安全上下文，HTTPS 和 localhost 可满足这一条件。普通局域网 HTTP 地址无法使用这些浏览器能力。

## 多页面使用

各页面独立选择会话，同一会话共用运行实例。断线重连后恢复当前状态和待处理审批。服务端需要保持运行和唤醒。

该服务按单用户使用设计，多个页面共享后端权限。会话生命周期见 [GUI 会话](../reference/gui/sessions.md)。
